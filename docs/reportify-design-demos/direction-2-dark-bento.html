01 — Core Pipeline

Natural language in. HTML report out.

STEP 01

Describe

接入 PostgreSQL，用一句话描述你要分析什么。不需要预先定义字段含义。

STEP 02

Agent Analyzes

自动画像数据、识别字段、制定计划、调用 Pandas 工具计算、校验结果。

STEP 03

Report Generated

Pydantic Schema → Jinja2 渲染 → 自包含 HTML。含图表、KPI、数据来源追溯。

04 — Architecture Modules

Seven modules. Clear boundaries.

01
🔌

Data Connector

统一数据源接入层。MVP 实现 PostgreSQL 连接器，设计可扩展接口。支持表结构发现、分页查询、只读安全校验、连接池管理。后续可扩展 MySQL、CSV、Excel、REST API。

SQLAlchemy PostgreSQL Read-only Extensible
02
🔬

Data Profiling

自动识别字段类型、统计分布、异常值。不猜测业务语义。

Pandas Auto-detect
03
🤖

Agent Engine

PydanticAI + DeepSeek。理解需求、规划分析、调用工具、组织结论。LLM 只做理解，不做计算。

PydanticAI DeepSeek
04
📊

Analysis Engine

确定性 Python 计算：趋势、分布、对比、异常检测。每个结果含计算口径和追溯信息。

Pandas Deterministic
05
📄

Report Engine

Agent 输出 Pydantic Schema → Jinja2 模板渲染 → 自包含 HTML。支持 KPI 卡片、ECharts 图表、数据表格、分析结论、数据来源追溯。禁止 LLM 直接生成 HTML——Schema 是 Agent 和模板之间的硬协议。

Jinja2 ECharts Pydantic Self-contained
06
⏰

Task & Scheduler

Cron 定时报告、失败重试、幂等控制。ARQ + Redis 异步队列。

ARQ Redis Cron
