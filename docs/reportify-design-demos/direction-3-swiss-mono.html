结论

本周 Duration 日均 127.4s，较上周 113.4s 上升 12.3%。第 5-6 天出现峰值（日均超 150s），异常检测标记 7 个异常点（>2σ）。分布右移，P95 从 210s 升至 245s。建议排查第 5-6 天的系统变更或流量突增事件。

04

Architecture

# Module Description Stack
01 Data Connector 统一数据源接入层。MVP 实现 PostgreSQL 连接器，可扩展接口。表结构发现、分页查询、只读安全校验。
SQLAlchemyPostgreSQL
02 Data Profiling 自动识别字段类型（数值/时间/分类/文本），计算空值、唯一值、分布、异常值。不猜测业务语义。
Pandas
03 Agent Engine PydanticAI + DeepSeek API。理解需求、规划分析、调用工具、组织结论。LLM 只做理解，不做计算。
PydanticAIDeepSeek
04 Analysis Engine 确定性 Python 计算：趋势、分布、对比、异常检测。每个结果含计算口径、数据范围、样本量。
Pandas
05 Report Engine Pydantic Schema → Jinja2 模板 → 自包含 HTML。KPI 卡片、ECharts 图表、数据表格、来源追溯。禁止 LLM 生成 HTML。
Jinja2EChartsPydantic
06 Task & Scheduler 定时报告、Cron 配置、失败重试、幂等控制。ARQ + Redis 异步队列。报告按日期归档。
ARQRedis
