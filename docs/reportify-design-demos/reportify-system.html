字段元数据

为字段添加展示名、描述、单位与标签，辅助报告展示与解释

ⓘ 标签只辅助展示和解释，不是分析的前置条件。没有用户标签时，系统使用原始字段名与自动识别的数据类型。字段类型识别不代表理解业务语义——例如 status=1 只能识别为分类值，系统不会自行认定它代表"成功"。
字段名识别类型展示名称单位用户标签描述
duration 数值 请求耗时 秒 核心指标性能 API 请求处理时长
created_at 时间 创建时间 — 时间维度 事件记录时间戳，用于趋势分析
status 分类 状态码 — 5 个分类值 未添加语义标签，系统仅识别为分类字段
response_size 数值 响应大小 KB 性能指标 响应体字节数
retry_count 数值 重试次数 次 性能指标 请求重试次数
error_code 分类 — — 空值率 91.7% 条件性填充字段，未添加用户标签
payload 文本 — — 高基数字段 非结构化文本，不参与数值统计
